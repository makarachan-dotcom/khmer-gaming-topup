# Catalog Branding Source Decision

The SMM platform cards will use the maintained Simple Icons package to render scalable platform brand marks in code, rather than storing copied image files in the web project. Game cards will use provider-returned HTTPS artwork only. The catalog filter excludes provider items whose game name, service name, or category indicates Thailand, Thai, Thai language, or a Thailand country marker.

The catalog keeps customer purchase actions disabled and does not create substitute products when an excluded item is removed.
