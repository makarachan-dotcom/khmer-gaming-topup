# Storefront UI 2026 upgrade

## Scope

- Expanded the storefront selector from 6 to 16 production UI systems.
- Added device previews and platform/dark filters in Admin.
- Added a final global polish layer for every customer-facing StorefrontLayout page.
- Improved focus rings, touch targets, form states, cards, alerts, transitions, spacing, and narrow-screen behavior.
- Added reduced-motion support.

## Design references

- Apple Human Interface Guidelines: familiar components, materials, fluid feedback, accessibility.
- Material Design 3: adaptive breakpoints, layout reflow, reachability, landmarks, and expressive motion.
- Baymard 2025 ecommerce research: prioritize checkout clarity and usable product-list patterns on desktop and mobile.

## UI systems

Classic, Guide, Boutique, Cupertino, Material You, Editorial, Zen Market, Commerce Pro, Gamer, Split, Showcase, Midnight, Aurora, Arcade Pro, Obsidian, and Solar Punk.
