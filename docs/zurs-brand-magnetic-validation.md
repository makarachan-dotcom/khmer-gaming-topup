# ZURS STORE Brand Magnetic Validation

The separate `MAGNET` label was removed. The `fx-magnetic` letter treatment now applies directly to the ZURS STORE name in the brand block, including staggered indexes for the letters in `ZURS STORE` and the existing reduced-motion fallback.

Desktop review at 1280px showed the animated brand name directly beside the logo without collision with navigation, balance, account, or sign-in controls. Mobile review at 375px confirmed that the animated ZURS STORE name remains visible in the compact header and does not create horizontal overflow.
