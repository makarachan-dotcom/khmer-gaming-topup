# Provider Artwork Sourcing

The requested competitor product page was reviewed on 22 August 2026 solely to evaluate whether it supplied explicit image reuse permission. It exposed an image URL but no reuse license or authorization statement. ZURS STORE does **not** copy, download, or embed that third-party storefront image.

The storefront instead renders game logos and package imagery only from the configured provider response (`imageurl`) when that provider supplies an HTTPS image URL. The Mobile Legends provider cover was retrieved from that configured provider response and published into managed project storage because the provider host prevented direct browser rendering. It is served to Vercel through `https://khmergame-girzfgts.manus.space/manus-storage/fzr-mobile-legends-global_d1d5e868.webp`; the Vercel hostname cannot serve `/manus-storage/...` directly because its SPA rewrite returns HTML for that path. If a provider has no approved image, the interface uses a neutral gamepad fallback rather than a copied asset or a fabricated product image.
