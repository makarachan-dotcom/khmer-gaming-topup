# Provider Artwork Sourcing

The requested competitor product page was reviewed on 22 August 2026 solely to evaluate whether it supplied explicit image reuse permission. It exposed an image URL but no reuse license or authorization statement. ZURS STORE does **not** copy, download, or embed that third-party storefront image.

The storefront instead renders game logos and package imagery only from the configured provider response (`imageurl`) when that provider supplies an HTTPS image URL. The Mobile Legends provider cover was retrieved from that configured provider response and published into managed project storage because the provider host prevented direct browser rendering. Vercel now serves that exact approved cover through its same-origin `/api/provider-artwork/mobile-legends` image endpoint. The endpoint fetches the stable managed-storage URL server-side, rejects non-image responses, and caches image bytes; it does not accept arbitrary URLs or copy competitor media. If a provider has no approved image, the interface uses a neutral gamepad fallback rather than a copied asset or a fabricated product image.
