# ZURS Homepage Reference Study

## Finsweet

Finsweet’s public homepage uses a clear centered headline, generous vertical whitespace, a limited-action hero, and a repeatable card rhythm. The navigation is compact and visually quiet, while primary actions have stronger contrast than secondary actions. ZURS should apply the same hierarchy to its dark hero, then move into light sections with consistent 12–16px rounded cards and restrained icon containers.

## Lordicon

Lordicon presents icons in coherent visual families and distinguishes animation triggers such as intro, hover, morph, and loop. For ZURS, the reference supports one consistent rounded line-icon system. Motion should be reserved for a control’s direct interaction or a real system state—not for unrelated decoration.

## Anime.js

Anime.js presents a modular animation API suited to short transform and opacity effects. ZURS should use one quick easing system for reveal and hover feedback, keep effects below 400ms, and avoid animating text decoration. Page sections may fade upward on first view while cards use a restrained lift instead of repeating loops.

## UseAnimations

UseAnimations provides Feather-inspired Lottie/SVG micro-icons for loading, checkmark success, menus, navigation, toggles, and actions. ZURS should continue to use these only for genuine loading or completion feedback and direct control transitions. The full product/category icon set should remain Lucide line icons for visual consistency.
